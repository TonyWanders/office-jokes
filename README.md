A program that writes one original funny line about office life to
`/output/entry.txt`, for the make.fun competition
[Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`) and prints exactly the line, with
no extra output. No network, no clock, no randomness. The line is 101
characters, inside the 1 to 199 gate.

## The line

```
I hit reply-all to ask everyone to stop hitting reply-all, and now 400 people agree I am the problem.
```
